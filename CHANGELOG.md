# Changelog

Every change to a range, a record, the method or the site, with absolute dates. Newest first. A range change always says which publication moved it and by how much.

## 2026-10-16

- Repository started (weekend step 2 of `docs/2026-10-16-kickoff.md`). README, CLAUDE.md (the two Belt Equation rules, adapted: commit on main and push; every design choice with confidence and an alternative), MIT licence for scripts and site, Creative Commons Attribution 4.0 for data, a commit-message date hook.
- Record schema proposed in `docs/record-schema.md`: four record types (factor, explanation, library entry, publication), one TOML file per record named for its id, a retired-ids list, and the rules the validator enforces. Twelve design choices listed with confidence and alternatives, proposed by Claude and **accepted by John as proposed the same evening**; two depart from the kickoff and say why (the folder is `data/explanations/`, not `data/theories/`; library entries link to explanations, not the other way round).
- One worked example of each record type under `data/`: the planets factor (fp) with a first-pass range of 0.1 to 1, log-uniform, from Sandberg, Drexler and Ord 2018; the dark forest explanation; Liu Cixin's trilogy as a library entry; the 2018 paper as the founding publication. **No headline yet**: one of seven factors exists.
- `scripts/compute.py validate` and a stubbed `run`, with 25 tests in `scripts/test_compute.py`.
- Public repository created at github.com/jfredson/quiet-galaxy and main pushed (asked by John 2026-10-16). The site scaffolded in `site/` on the Sentient Horizons design standard with a holding home page, `scripts/export.py`, `scripts/publish.py` and the deploy workflow; a preview deployed by hand to quietgalaxy.jfredson.workers.dev. The `CLOUDFLARE_ACCOUNT_ID` repository secret set; the API token and the domain registration wait on John.
- Both domains registered by John through Cloudflare's registrar on 2026-10-16 and attached to the site the same evening: thequietgalaxy.com serves the site, and www.thequietgalaxy.com, whereareallthealiens.com and its www forward to it with a permanent redirect that keeps the path. The forwarding is done by a small worker in front of the static files (`site/worker/redirect.js`) rather than a dashboard redirect rule, so that it lives in the repository and every deploy carries it; the four addresses are custom domains on the one Worker (`site/wrangler.jsonc`), the Belt Equation's pattern.
- The name ruled by John: The Quiet Galaxy, at thequietgalaxy.com, with whereareallthealiens.com forwarding to it.
